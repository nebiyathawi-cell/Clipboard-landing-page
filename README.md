## Overview

The Clipboard landing page introduces an application that helps users
keep track of copied content across their devices.

I built this page to practice HTML structure, responsive layouts,
and styling with Tailwind CSS.

## Features

- Responsive design for mobile and desktop screens
- Feature sections with images and descriptions
- Download buttons
- Company logos section
- Responsive footer
- Hover and focus states for interactive elements

## Built With

- HTML5
- Tailwind CSS
- Mobile-first workflow

## What I Learned

While building this project, I practiced:

- Creating semantic HTML sections
- Using Tailwind CSS utility classes
- Building responsive layouts with Flexbox and Grid
- Using responsive breakpoints such as `sm:` and `md:`
- Improving spacing, typography, and alignment
- Organizing a landing page into reusable sections

## Getting Started

To view the project locally:

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

If you use a development server or Tailwind CSS build command,
follow the setup instructions for your project.
